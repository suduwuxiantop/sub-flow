Sub-Flow 智能分流订阅转换

输入任意机场的订阅链接，按你的使用习惯自动生成分流规则，一份 Clash 订阅搞定 AI / 流媒体 / 社交 / 游戏

规则会优先于上方预设分类生效，最多 20 条。域名/关键字请勿包含 http:// 或路径，例如 example.com、.example.com、example。

怎么用
  1. 粘贴你现有机场的订阅链接（支持 vmess / trojan / vless / ss / hysteria2，以及已经是 Clash 格式的订阅）
  2. 勾选你关心的分类，比如常看 Netflix 就勾流媒体，常用 ChatGPT 就勾 AI 工具；分类多了可以用上方搜索框快速查找
  3. 有特殊需求可以在「自定义分流规则」里自己添加域名 / IP 段，指定走代理、直连还是拦截，优先级高于预设分类
  4. 点生成，把新链接粘到 Clash 客户端的订阅里，以后每次刷新都会自动带着你的分流规则

没勾选的分类不会单独分组，会跟着主节点选择器走，不影响正常使用。规则集来自社区维护的开源规则库，每天自动更新一次。
